### Forensic Defect Manifestation:
1. **Immediate "sir" address term**: Alisha's very first bubble is `"ohh hi sir"`. The ground-truth corpus shows "sir" appears in only 0.83% of turns, but previous prompts declared it as her "favorite playful address term".

4. **Fact Ledger 0-Overlap Fallback**: `lookup_for_prompt` in `packages/facts/__init__.py` falls back to sorting by `-importance` when word overlap is 0, guaranteeing that the top 6 seeded facts (Biochemistry, Age 20, Mauritius, Mum, Faith) are injected into completely unrelated queries.

## 4. Live Voice Path Audit & Baseline Output

### Path Traced:
`USER SENDS MESSAGE`  
-> `POST /api/voice/process` (`services/api/server.py` line 775)  
-> `context_engine.process_turn(..., voice_mode="always")`  
-> `synthesize_speech(spoken_text)` in `packages/voice/realtime_tts.py` (line 782)  
-> `_synthesize_async(text, voice="en-GB-MaisieNeural")` via Microsoft Edge TTS!  
-> Saved to `/voice/generated/alisha_<hash>.mp3`

### Live Baseline Output (`"hey cutie"`):
- Output URL: `/voice/generated/alisha_a564586bb8acfa41.mp3`
- Audio Format: 24kHz MP3 generated by Microsoft Cognitive Services / `edge-tts` (`en-GB-MaisieNeural`)

### Forensic Voice Findings & Proven Root Causes:
1. **ROOT CAUSE: LIVE PATH DOES NOT USE QWEN CLONING**:
   - The production server never invokes Qwen3-TTS. It exclusively calls `edge-tts` with a stock neural voice (`en-GB-MaisieNeural`).
2. **ExecuTorch Workstation Path Disconnected & Broken**:
   - `alisha_tts_workstation.py` is not wired to `services/api/server.py`.
   - `voice_v1/prompt_item.pt` contains synthetic random noise (`torch.randint(0, 3072, ...)` and `torch.randn(2048)`), NOT true Qwen3-TTS codec tokens or speaker embeddings.
   - When ExecuTorch generation fails or is in fallback mode, `alisha_tts_workstation.py` silently copies `reference.wav` as the output file (`shutil.copy2(ref_audio_path, output_path)`).
3. **ExecuTorch Graph Lacks ICL Conditioning Support**:
   - Introspection of `talker_int8.pte` via `scripts/inspect_pte_signatures.py` revealed that the exported graph accepts only `[1, 10, 2048]` embeddings and KV caches. It does not accept `ref_code`, `ref_spk_embedding`, or interleaved reference text natively.
4. **Missing Python Dependencies**:
   - The virtual environment does not contain `transformers` or `qwen_tts`.

1. **Refactor Text Pipeline**:
   - Eliminate `DURABLE_MEMORIES` injection in both `packages/context/__init__.py` and `packages/engine/context_rag.py`.
   - Sanitize `_build_style_card_v2()` into a purely constitutional style card (lowercase distributions, burst structure, slang usage, tone) without biographical anchors.
   - Adjust `lookup_for_prompt` in `packages/facts/__init__.py` to return zero facts when query relevance is zero.
   - Remove canned strings from `segment_and_guarantee_bursts`.
   - Implement `packages/life/engine.py` for persistent, mundane simulated events separated strictly from the historical fact ledger.
   - Introduce session retrieval ledger with recency cooldowns.

   - Establish the canonical PyTorch Qwen3-TTS 1.7B Base voice cloning pipeline with authentic reference audio and transcript.

   - Wire production voice route to this PyTorch backend under `USE_QWEN_TTS_SERVICE=true` and `ALLOW_STOCK_TTS_FALLBACK=false`.
3. **Evaluation & Parity Testing**:
   - Run multi-turn text regression benchmarks across diverse topics.
   - Compare audio clones against genuine Alisha recordings and verify absence of reference transcript echoes.
